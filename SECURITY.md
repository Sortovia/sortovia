# Security

Sortovia moves and renames files, and it can sign in to services you set up (such as Real-Debrid), so
security problems matter.

## Reporting a problem

Please don't open a public issue. Use **Report a vulnerability** on this repository's **Security** tab. That
sends a private report that only the maintainer can see. You'll get a reply within a week.

## Supported versions

Only the newest version gets fixes. Sortovia updates itself from its Kodi repository, so most people are on it.
